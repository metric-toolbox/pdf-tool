Rotate a PDF and Actually Save It

Rotating in a PDF viewer only changes the view — the file stays sideways for everyone else. This tool permanently rotates every page and writes the change into the file, so it opens correctly everywhere.

Features

  • Three angles: 90° clockwise, 180°, or 90° counter-clockwise.
  • All pages at once: perfect for scans where the whole batch came out sideways.
  • Lossless: rotation changes orientation metadata only — zero quality loss.
  • Private & free: processed on your device, no sign-up, no watermark.

Frequently Asked Questions

Everything people ask about our free rotate pdf tool.

How do I rotate a PDF and save it permanently?

Upload the PDF, choose an angle and click Rotate — the downloaded file has the rotation saved inside it, so it opens correctly in every viewer.

Does rotating reduce the quality of my PDF?

No. Rotation only updates page orientation — text and images are untouched, so there is zero quality loss.

Can I rotate just one page?

Extract that page with our free Split PDF tool, rotate it, then merge it back — all without sign-up.

Why does my PDF look fine in my viewer but sideways for others?

Your viewer rotated the display only. Use this tool to write the rotation into the file itself.
